# Painel de Análise de Vendas com Visualização de Dados

Projeto prático em Python (pandas, numpy, matplotlib e seaborn) que consolida dados de vendas de várias lojas, calcula métricas e gera visualizações.

## Conteúdo
- `painel_vendas.ipynb` — notebook completo (20 itens, já executado)
- `vendas.csv` — dataset fictício
- `graficos/` — gráficos gerados (PNG)
- `resumo_analitico.csv` — resumo consolidado dos principais resultados

## Como executar
```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook painel_vendas.ipynb
```
Ou abra o notebook no Google Colab (envie o `vendas.csv` junto; se não existir, o notebook cria um automaticamente).
